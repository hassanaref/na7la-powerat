## ⚡ ما هو نظام نحلة باورات (Na7la Powerat)؟

**نحلة باورات 2.0** (`na7la powerat`) يطور المشروع إلى منصة سحابية غير متزامنة متكاملة توفر إدارة أجهزة متعددة، بوت تليجرام تفاعلي (`@Na7laPoweratBot`)، جداول ومؤقتات ذكية، تتبع استهلاك الكهرباء وحساب التكلفة بالجنيه المصري، وتنبيهات أمان فورية لحماية الأجهزة.

---

## ✨ المميزات الرئيسية (البديل الكامل لتطبيق Voltra)

1. **بدون تعديلات على الراوتر أو فتح بورتات في المنزل**: المشترك يتصل بنفسه بالسيرفر عبر اتصال TCP خارجي، فيعمل مباشرة عبر أي شبكة ومن خلف NAT و4G والآي بي الديناميكي.
2. **دعم شامل لجميع إصدارات الفيرموير (بورتات متعددة)**:
   - بورت **`10086`**: لفيرموير `0.1.54`.
   - بورت **`21197`**: لفيرموير `0.1.55-1.0.141` و `0.1.55-1.0.146`.
3. **بوت تليجرام متكامل (`@Na7laPoweratBot`)**:
   - ربط المشترك بسهولة عبر عنوان الماك (MAC Address).
   - تحكم مستقل بكل مخرج من المخارج الأربعة مع قراءة الواط الحية.
   - زر رئيسي لتشغيل أو فصل كل المخارج بضغطة واحدة.
   - إعادة تسمية المخارج بأسماء مخصصة (راوتر، كمبيوتر، شاحن...).
   - مؤقتات عد تنازلي للفصل التلقائي (بعد 15 دقيقة، 30 دقيقة، ساعة...).
   - جداول ومواعيد يومية متكررة للتشغيل والإيقاف تلقائياً.
   - واجهة ثنائية اللغة بالكامل (عربي / إنجليزي).
4. **حساب استهلاك الكهرباء والتكلفة بالجنيه المصري (EGP)**:
   - قياس القدرة اللحظية (بالواط) لكل مخرج وللمشترك ككل.
   - استهلاك الطاقة التراكمي (كيلوواط/ساعة kWh).
   - حساب تكلفة الفاتورة بالجنيه وفقاً لشرائح الكهرباء المصرية.
5. **تنبيهات أمان فورية عبر تليجرام**:
   - إشعار عند انقطاع الكهرباء أو فصل المشترك.
   - إشعار عند عودة الكهرباء واتصال المشترك.
   - إنذار فوري عند الحمل الزائد (>3500 واط أو >15.5 أمبير).
   - إنذار ارتفاع الحرارة (>65° مئوية).
6. **توافق كامل مع تطبيق أندرويد الأصلي**: الحفاظ على مسارات `/api/state` و `/api/onoff`.

## 🚀 طريقة التشغيل السريعة

### 1. المتطلبات
* مشترك LG U+ / Jinheung **MTTL-W01** الذكي.
* شبكة واي فاي بتردد **2.4 GHz فقط** (المشترك لا يدعم 5 GHz).
* سيرفر سحابي Linux (مثل AWS EC2) أو كمبيوتر يعمل باستمرار.
* بايثون 3.10 فأحدث.

### 2. تشغيل السيرفر
```bash
git clone https://github.com/hassanaref/powerk.git
cd powerk

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# تشغيل الاختبار الذاتي للتأكد من كل المكونات
python powerk.py selftest

# بدء السيرفر
python powerk.py serve
```

### 3. ربط المشترك (لأول مرة فقط)
1. اضغط مطولاً على الزر الرئيسي للمشترك لمدة **10 ثوانٍ** حتى تومض اللمبة بسرعة كبيرة.
2. اتصل من اللاب توب أو الهاتف بشبكة المشترك `TONLY_TAP_XXXXXXX` (الباسورد: `LGU_XXXXXXX`).
3. نفذ أمر الإعداد:
   ```bash
   python powerk.py provision --ip <آي_بي_السيرفر_الخارجي> --ssid "<اسم_الواي_فاي>" --password "<باسورد_الواي_فاي>"
   ```
4. **خطوة أساسية**: بعد طباعة كلمة `Done`، **افصل فيشة المشترك من الحيطة تماماً لمدة 20 ثانية** ثم أعد تركيبها.
5. ستثبت لمبة الواي فاي وسيتصل المشترك بالسيرفر فوراً.
